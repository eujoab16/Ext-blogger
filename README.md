## 📌 Sobre o Projeto

O **Blogger Studio Pro** (Ext-Blogger) foi desenvolvido para simplificar a vida de desenvolvedores, designers e criadores de conteúdo que trabalham na plataforma Blogger (Blogspot). 

Com este painel interativo, você não precisa mais procurar códigos básicos de templates XML, tags de gadgets ou buscar ícones manualmente. Tudo está disponível com um clique, pronto para copiar e colar diretamente no seu blog.

---

## ⚡ Principais Funcionalidades

### 📁 1. Templates Prontos (XML)
- **Template Zerado sem Post:** Estrutura limpa em XML para iniciar projetos do zero sem interferências.
- **Template Zerado com Post:** Estrutura base incluindo a seção e widget principal de postagens (`Blog1`).
- **Template SKIN:** Tag otimizada `<b:template-skin>` para estilização CSS no modo de layout.

### 🧩 2. Snippets de Gadgets & Widgets
- **Seções de Gadgets (`<b:section>`):** Crie novas áreas de widgets no layout.
- **Widget de Postagens:** Código limpo para o widget nativo de postagens do Blogger.
- **HTML / JavaScript (`<b:widget type='HTML'>`):** Snippets para inserção rápida de scripts personalizados.

### 🎨 3. Biblioteca Completa Font Awesome 6.5
- Link CDN pronto para cópia e inserção no `<head>`.
- Milhares de ícones organizados por categorias:
  - 🏠 **Gerais & Utilitários (Solid)**
  - 🌐 **Redes Sociais & Marcas (Brands)**
  - 🛒 **Comércio, Lojas & Pagamentos**
  - ⬅️ **Setas, Direções & Navegação**

### 🛠️ 4. Geradores & Utilitários Integrados
- 👤 **Gerador de Pessoas:** Crie dados fictícios para testes em formulários e blogs.
- 🔒 **Gerador de Senhas Seguras:** Crie senhas fortes e personalizadas.
- 🧹 **Organizador & Formatador de Código:** Limpe e identifique HTML/CSS.
- 🎨 **Seletor de Cores (Color Picker):** Escolha cores HEX/RGB rapidamente.
- 🌗 **Gerador de Sombras CSS (`box-shadow`):** Crie efeitos visuais profissionais.
- 💬 **Gerador de Link do WhatsApp:** Crie links diretos para conversas com mensagens personalizadas.
